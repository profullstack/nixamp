# BackToSchool.help Amazon artwork source

`source/showcase.html` renders the exact-size Amazon Appstore compositions using
the canonical BackToSchool.help icon and color palette from `backtoschool/`.

`source/education-backdrop.png` was generated in ads-marketing mode with this
final prompt: a text-free 16:9 education backdrop using deep purple, coral,
gold, and cream; abstract open-book pages, learning doodles, and a path toward
discovery; calm negative space on the left; no people, text, logos, or UI.

All lesson titles, host names, chat messages, and audience counts in the
showcase are fictional.
