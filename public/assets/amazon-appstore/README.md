# Amazon Appstore upload assets

These files are ready for the English (U.S.) Amazon Appstore listing.
`MANIFEST.json` maps every upload field to its file. Upload the media files
individually in Amazon's form; the adjacent ZIP is provided for handoff only.

two tablet icons preserve transparency as required.
