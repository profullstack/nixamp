# Interface languages

The browser/PWA, desktop player, terminal player/admin and BackToSchool client
use the same 18-language target list as audio translation. Interface and spoken
translation languages are independent.

Selection order is an explicit saved choice, supported system preferences, then
English. Browser settings use `nixamp.ui.language`; the desktop synchronizes the
page and native menu through its restricted language bridge. The terminal reads
`NIXAMP_UI_LANGUAGE`, `LC_ALL`, `LANGUAGE`, `LC_MESSAGES`, and `LANG`, and accepts
`--ui-language de` or `--ui-language=de`. Language tags such as `es-MX` and
`de_DE.UTF-8` resolve to the supported base language.

`src/i18n.ts` loads one bundled catalog on demand. There are no translation API
calls or provider charges. English is the message fallback; a failed language
file load keeps the current interface usable. `I18n` instances are independent;
never share a mutable singleton across server requests for different users.

The shared catalog covers navigation, playback, translation controls, accounts,
forms, panels, desktop commands, and classroom controls. Existing longer prose
and operational messages retain their English fallback until given catalog
entries. `src/ui-aliases.ts` maps existing variants to concise translated labels
while keeping the original English wording.

Add messages to `src/locales/en.ts` and every other catalog; `Catalogue` enforces
key coverage. Use `t(message, values)` for plain strings and `Intl` for numbers,
currency and dates. Keep translators' prose out of HTML interpolation: use the
DOM bindings or escape text when generating markup. Protocol values, form names
and user content must never be translated.

In static or generated markup, mark application text with `data-i18n` and
accessible attributes with `data-i18n-aria-label`, `data-i18n-title`, or
`data-i18n-placeholder`. Mark a leaf element, not a parent containing controls.
Use `uiText` and `uiAttribute` for dynamic labels. These update existing nodes;
they do not reload, focus, scroll, or translate arbitrary inserted content.

Run `bun test test/i18n.test.ts`, `bun run typecheck`, and the web and classroom
builds. `web/scripts/check-interface.mjs` checks the actual built interfaces with
Chromium, including system defaults, persistent choices, keyboard operation,
selector contrast, Arabic, mobile layout, form submissions, and preservation of
content and focus. The Browser player workflow also checks intro audio analysis.
